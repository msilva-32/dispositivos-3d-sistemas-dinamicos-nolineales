# Dispositivos experimentales impresos en 3D para sistemas dinámicos

Este repositorio reúne archivos STL, imágenes y orientaciones de montaje de dispositivos experimentales impresos en 3D para trabajar sistemas dinámicos en cursos de Física.

## Dispositivos incluidos

1. Péndulo magnético
2. Pájaro carpintero
3. Péndulo doble

## Contenido del repositorio

- Archivos STL de cada dispositivo.
- Imágenes de los modelos 3D.
- Fotografías de las piezas impresas.
- Parámetros básicos de impresión.
- Lista de materiales no impresos.
- Orientaciones breves de montaje.
